This entry writes a single sentence that explains the modern internet to a time traveler who has just stepped out of the year 1800, using only things a person of that year already knows: post offices, libraries, roads, letters, books, and towns. The sentence paints one picture, every post office and library on earth joined by a single road, so that a letter outruns any horse and any book stands open on the traveler's own table, day or night. No word in it was coined after 1800.

## Run it

```sh
python3 main.py
```

The program writes the sentence to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`).
